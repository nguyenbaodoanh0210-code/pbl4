# Model artifacts

Active artifacts are generated by the scripts in `../scripts/` and consumed by `../app/ai/`:

- `greenhouse_demo_model.joblib` is the sensor-based recommendation model.
- `chili_disease_model.keras` is the image classifier.
- The matching `*_metadata.json` files contain evaluation results and model metadata.

Files under `legacy/` are preserved from the original project. Their training source and input schema have not been verified; application code must not load them.
